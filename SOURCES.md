Use current official documentation when implementing or revisiting component behavior.

Key current capability facts used in this design:
- `ui5-navigation-layout` exists and is explicitly intended for header + side navigation + content layouts.
- `ui5-flexible-column-layout` supports list-detail-detail with up to three columns and responsive behavior.
- `ui5-shellbar` provides application header features including logo/profile/search/notifications.
- `ui5-form` provides responsive enterprise form layout.
- modern `ui5-table` supports responsive overflow and optional selection/growing/virtualization features.
- non-default UI5 themes require library theme assets to be imported.
