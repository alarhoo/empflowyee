# hcm-leave-contract

Universal Leave DTOs and synchronous field validation shared by browser forms and
server commands. Quantities are decimal strings within numeric(18,6), never binary
floating-point values. Incomplete policy drafts remain editable; publication
validation reports missing explicit configuration without adding defaults.

See the [policy field design](../../../../docs/hcm/apps/leave-policies/TDD.md#policy-field-implementation-contract).
