# HCM job architecture contract

Runtime-universal vocabulary, DTOs and request parsers of the job architecture domain
(`hcm-job-architecture-contract`): version statuses, career track kinds, requirement types and
units, and the catalogue version, job family, track, level, band, grade and job profile DTOs.
See the [job architecture technical design](../../../../docs/hcm/domains/job-architecture/TECHNICAL-DESIGN.md#contract).
