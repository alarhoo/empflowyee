# HCM job architecture domain

Pure job architecture rules (`hcm-api-job-architecture-domain`): draft-only change, the
Draft → InReview → Published lifecycle, successor effective dates, two-level families
(DEC-HCM2-005), allowed grades with exactly one default and unique codes. See the
[job architecture technical design](../../../../../docs/hcm/domains/job-architecture/TECHNICAL-DESIGN.md#policy).
