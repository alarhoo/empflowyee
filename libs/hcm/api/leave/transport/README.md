# hcm-api-leave-transport

Authenticated Leave policy list, exact-version read, draft create/update,
successor-version and type-option HTTP routes. Controllers delegate to source
application commands and reuse existing origin, media, retry-key and safe error
handling. Publication and other unfinished capabilities are not mounted.

See the [admitted API](../../../../../docs/hcm/apps/leave-policies/TDD.md#api).
