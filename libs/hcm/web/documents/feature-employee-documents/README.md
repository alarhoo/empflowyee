# Employee Documents

Domain-owned HR worker attachment workspace. Native FCL keeps server filters/list in
the begin column and an approved Object Page with Overview/Versions in the mid column.
Complex creation has a dedicated route; version upload and sharing use focused dialogs.
All data comes from the documents API. No feature CSS or frontend business fixtures.

See [TDD](../../../../../docs/hcm/apps/employee-documents/TDD.md) and
[storage operations](../../../../../docs/hcm/engineering/DOCUMENT-STORAGE.md).
