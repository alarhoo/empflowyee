# HCM document templates

Documents-owned lazy Angular feature using native FlexibleColumnLayout, an approved
Object Page and focused file-upload dialogs. Signal Forms bind real NestJS API data;
no feature CSS or frontend business fixtures.

See the [technical design](../../../../../docs/hcm/apps/document-templates/TDD.md),
[storage operations](../../../../../docs/hcm/engineering/DOCUMENT-STORAGE.md) and
[validation](../../../../../docs/hcm/testing/HCM-1-DOCUMENT-TEMPLATES-VALIDATION.md).

Run `pnpm nx lint hcm-web-documents-feature-document-templates` and the live
`document-templates.spec.ts` browser acceptance with the local API/web running.
