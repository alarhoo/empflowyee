# App Catalogue Configuration

Read-only native FCL/Object Page feature. The complete bounded canonical app
projection is filtered client-side; business account choices use server paging.
Discovery explanations come from the authorized server and never impersonate an
account. There are no mutation controls, business fixtures or feature CSS.

See the [approved design](../../../../../docs/hcm/apps/app-catalogue-configuration/TDD.md).
Generated with the official Nx Angular library generator, style `none`, standalone
OnPush components and the four domain ownership tags in project.json.

Run the project lint target, access-control API integration tests and the live
catalogue browser acceptance suite before claiming implementation readiness.
