# Tenant Access Reviews

Lazy, domain-owned native FlexibleColumnLayout with a begin-column review list and
mid-column Object Page (Overview and Assignment snapshot). Focused start, decide,
refresh and close actions use native dialogs with Signal Forms and dirty guards.
All queries and commands use the access-control data-access library and real APIs;
there is no feature CSS or fixture business data.

See [technical design](../../../../../docs/hcm/apps/tenant-access-reviews/TDD.md)
and [validation](../../../../../docs/hcm/testing/HCM-1-TENANT-ACCESS-REVIEWS-VALIDATION.md).
