# hcm-web-ux-forms

Shared HCM forms presentation contracts using native UI5 controls. Import from `@empflowyee/hcm-web-ux-forms`.

See the [standard and public API](../../../../../docs/hcm/ux/forms/signal-form-standard.md) for state ownership, supported behavior and production integration responsibilities. [Storybook](../../../../../docs/hcm/ux/storybook.md) demonstrates deterministic local fixtures. This library owns no HTTP clients or business rules.

Run `pnpm nx test hcm-web-ux-forms` and `pnpm nx lint hcm-web-ux-forms`. Browse examples with `pnpm nx storybook hcm-web`.
