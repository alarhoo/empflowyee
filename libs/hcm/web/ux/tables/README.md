# hcm-web-ux-tables

Shared HCM tables presentation contracts using native UI5 controls. Import from `@empflowyee/hcm-web-ux-tables`.

See the [standard and public API](../../../../../docs/hcm/ux/tables/enterprise-table-standard.md) for state ownership, supported behavior and production integration responsibilities. [Storybook](../../../../../docs/hcm/ux/storybook.md) demonstrates deterministic local fixtures. This library owns no HTTP clients or business rules.

Run `pnpm nx test hcm-web-ux-tables` and `pnpm nx lint hcm-web-ux-tables`. Browse examples with `pnpm nx storybook hcm-web`.
