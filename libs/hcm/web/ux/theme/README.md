# hcm-web-ux-theme

Owns native UI5 theme switching, semantic token application and the validated tenant accent bridge.

Import through `@empflowyee/hcm-web-ux-theme`. See the [HCM maintainer guide](../../../../../docs/hcm/architecture/shell/README.md) for architecture, constraints and workflows.

```sh
pnpm nx lint hcm-web-ux-theme
pnpm nx test hcm-web-ux-theme
```
