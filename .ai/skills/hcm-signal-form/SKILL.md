# HCM Signal Form

## Use when

Building a new HCM data-entry/edit form.

## Procedure

1. Use Angular Signal Forms unless the TDD records an exception.
2. Define a typed form model and validation schema.
3. Use UI5 controls and form layout primitives verified against installed wrappers.
4. Implement dirty state, save/cancel, submission and error mapping.
5. Keep authoritative business rules on the backend.
6. Add accessible labels/descriptions/errors.
7. Add Storybook states: valid, invalid, saving, server validation error, read-only.
8. Unit test our validation/orchestration.
