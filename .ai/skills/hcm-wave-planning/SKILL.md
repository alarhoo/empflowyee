# Prepare an HCM wave

Resolve all apps in a delivery wave, domain prerequisites, shared contracts and blockers. Follow the readiness scope in [the authoritative delivery roadmap](../../../docs/hcm/roadmap/HCM-DELIVERY-WAVES.md), including explicitly approved stage exceptions. Finalize every app FDD/TDD in that required scope before implementation begins. Do not implement while any `BLOCKS_THIS_APP` item in that scope remains.
