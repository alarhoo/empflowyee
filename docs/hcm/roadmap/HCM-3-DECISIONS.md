## APPLICATION

These resolutions replace the preparation recommendations, particularly the
proposed universal rest rule, step-up prerequisites and LOP balance treatment.
The initial Leave seed is configuration, not statutory certification. Unspecified
tenant policy parameters must be explicitly configured before publication;
there is no implicit unlimited cap or fallback entitlement.

Scopes, DTO shapes, database mappings, worker leases, native control composition
and test mechanics are technical design responsibilities delegated to Codex.
The five later-capability items remain visible warnings, never blockers for
current implementation. They cannot be activated through an unrestricted flag.
