# HCM specification authority

Use the [current HCM authority model](HCM-AUTHORITY.md) and repository
[constitution](../../../AGENTS.md#source-of-truth-order).

Only current approved requirements, FDDs, TDDs, ADRs and domain documents are
implementation inputs. Reference inventories and earlier dossiers cannot supply
missing behavior or override current architecture. Resolve missing requirements in
the owning current document before implementation; do not add lineage or provenance
fields to current app/domain metadata.
