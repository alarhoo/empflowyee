# ADR-0003 — HCM Storybook workshop

## Status

Accepted

## Decision

Configure Storybook on the existing `hcm-web` Nx application and use it as the single HCM visual workshop across HCM web UX libraries.

The approved 2026-09-22 correction makes this a curated production UX catalog. Canonical entries render the exact production implementation consumed by the application. Story-only layouts are prohibited; deterministic fixture data remains appropriate. Theme Lab is an exploratory consumer. Only Dynamic Page and Object Page are in the first corrected iteration; other patterns remain deferred.

Use the stable Storybook Angular integration generated by Nx for the installed versions. Do not adopt `@storybook/angular-vite` while Storybook 10.6 still labels it preview.

## Consequences

- no new production deployable
- one visual surface for themes/floorplans/forms/tables
- Nx can cache/affect Storybook tasks
- Storybook can depend on HCM libraries through the HCM app composition root without reversing library dependency direction
- migration to Angular-Vite may be reconsidered when stable
