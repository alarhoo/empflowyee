# Data Ownership Boundaries

## Account owns

- customer account lifecycle
- trial/subscription lifecycle
- commercial entitlements
- organization onboarding/provisioning request
- tenant slug/hostname assignment
- buyer/account administrators
- customer branding configuration source

## HCM owns

- employee/workforce data
- organization operating structure used by HCM
- work locations
- positions
- leave/time/attendance/payroll/performance/etc.

## Console owns

- platform operations metadata
- tenant lifecycle/support metadata
- platform service diagnostics
- platform-level audit/support records

Console operators do not receive unrestricted rights to modify customer HCM business records.
