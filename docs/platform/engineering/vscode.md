# VS Code Workspace

VS Code is the primary local engineering surface for empFLOWyee. AI assistants operate against the repository; chat history is never the source of truth.

Recommended extensions are listed in `.vscode/extensions.json`:

- Nx Console
- Angular Language Service
- ESLint
- Prettier

Use Nx Console/CLI to inspect the project graph and affected tasks. Codex can work directly against this repository, but must follow `AGENTS.md` and the canonical `docs/` sources.
